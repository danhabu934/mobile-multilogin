Central de instalação

Comece com clareza.

O diagnóstico independente é a primeira entrega. A instalação completa e a abertura de perfis permanecem indisponíveis nesta edição.

01

Baixar

Consulte Downloads. Somente versões realmente publicadas terão link.

Ver disponibilidade
02

Executar o instalador

No Windows, siga o assistente. No Mac, abra o DMG e copie o app para Aplicativos. Aguarde uma versão validada antes de instalar.

03

Verificar componentes

Abra Nexo Diagnóstico e clique em Verificar computador. Confira RAM, CPU, Java, SDK, ADB e aceleração.

04 / PENDENTE

Preparar Android

A instalação automática do SDK e das imagens Android não faz parte do diagnóstico.

05 / PENDENTE

Iniciar o worker

O aplicativo de diagnóstico não inicia serviços do projeto existente.

06 / PENDENTE

Conectar ao painel

A conexão automática ainda não está disponível nesta edição.

07 / PENDENTE

Abrir o primeiro perfil

Esta etapa depende de uma edição independente do runtime Android e de testes de ponta a ponta.
